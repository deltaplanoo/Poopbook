# 💩 PoopBook

A mobile-first PWA for a closed group of friends to log and track bathroom
habits, compete in leagues, and analyze the, uh, output.

**Stack:** SvelteKit (Svelte 5, runes) · Tailwind CSS 4 · PocketBase · Leaflet · Chart.js · vite-plugin-pwa

## Quick start

### 1. Backend — PocketBase

Download the PocketBase binary for your platform from
<https://pocketbase.io/docs/> and place it in the `pocketbase/` directory,
then:

```bash
cd pocketbase
./pocketbase serve
```

On first start PocketBase automatically applies the migration in
`pocketbase/pb_migrations/`, which creates the `poops` and `leagues`
collections with their API rules — no manual schema setup needed.

Create the first admin account when prompted (or via
`./pocketbase superuser upsert you@example.com yourpassword`), then open the
admin UI at <http://127.0.0.1:8090/_/> if you want to poke around.

macOS one-liner to fetch the binary (check the latest release number first):

```bash
cd pocketbase
curl -L -o pb.zip https://github.com/pocketbase/pocketbase/releases/download/v0.39.7/pocketbase_0.39.7_darwin_arm64.zip
unzip pb.zip pocketbase && rm pb.zip
```

### 2. Frontend — SvelteKit

```bash
npm install
cp .env.example .env   # adjust PUBLIC_POCKETBASE_URL if PocketBase isn't on localhost:8090
npm run dev
```

Open <http://localhost:5173>, sign up, and start logging.

### 3. Production build

```bash
npm run build      # static SPA output in build/ (installable PWA)
npm run preview    # serve the production build locally
```

Deploy `build/` to any static host. Remember the PWA needs HTTPS (or
localhost) for the service worker and geolocation to work, and set
`PUBLIC_POCKETBASE_URL` to your public PocketBase URL before building.

## Database schema

| Collection | Fields | Notes |
| --- | --- | --- |
| `poops` | `user` (relation→users), `timestamp` (date), `latitude`/`longitude` (number), `note`/`place` (text), `rating` (number 1–5) | create only as yourself; update/delete owner-only |
| `leagues` | `name` (text), `owner` (relation→users), `members` (relation→users, multiple) | any authenticated user can update (so friends can join); delete owner-only |

Access model: this is a **closed friend-group app** — every authenticated user
can read everyone's poops, leagues, and user names (required for league maps
and leaderboards). Don't open signups to strangers; PocketBase's users
collection is the only registration path.

## App tour

- **💩 Log** (`/`) — one-tap logging: auto-fetched geolocation, place, 1–5
  poop rating, note. Shows your recent entries.
- **🗺️ Map** (`/map`) — all your drops on a Leaflet map; pick a league to see
  every member's markers, color-coded per user.
- **🏆 Leagues** (`/leagues`) — create a league, search & join existing ones,
  and battle it out on leaderboards (total logs, average rating).
- **📊 Stats** (`/analysis`) — KPIs plus charts: logs per week, top places,
  rating distribution.

## PWA

Configured via `@vite-pwa/sveltekit` in `vite.config.ts`:
`theme_color: #6a5248` (main brown), `background_color: #f5e5aa`
(butter yellow), auto-updating service worker, installable on iOS/Android.
Icons are generated by `node scripts/gen-icons.mjs` (no image deps — pure
math + zlib).
